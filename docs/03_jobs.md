# 03. 작업 만들기

작업 = 항목 목록. 항목마다 판 위 자리(x · y), 돌림(°), 높이 z 를 가진다. 위 탭에서 만들어 [작업에 넣기].

## 항목 종류

| 탭 | 항목 `type` | 내용 |
|---|---|---|
| 그리기 | `draw` | 판 그림 위에서 끌어 그림(한 번 끌기 = 한 획). 자유 · 꺾은선(눌러 찍고 두 번 눌러 끝). 다듬기 mm(가우스), 높이 z |
| 도형 | `shape` | 원 · 사각형(모서리 둥글림) · 다각형 · 별 · 8자 · 선 · 나선 · 십자 · 채우기(사각 · 원 안 지그재그, 간격 · 각도). 시계 방향 선택 |
| 글씨 | `text` | 한 획 글꼴: 영문 대문자 · 숫자 · 기호 일부, 줄바꿈. 높이 · 간격 · 돌림. 못 쓰는 글자는 건너뛰고 알림 |
| 사진 · 그림 | `draw` (획으로 바뀜) | PNG · JPG → 중심선 · 윤곽선 · 채우기 선 · 둘 다 ([04](04_image_to_path.md)) |
| 배열 찍기 | `grid` | 칸마다: 옮기는 높이 → 곧게 내림 → 그리퍼 먼저 · 기다리기 · 그리퍼 나중 → 들기 |
| 파일 | `gcode` · `svg` · `csv` | 아래 |
| 동작 | `action` | 그리퍼 값(0 – 1000) · 기다리기(s) · 멈춤(확인 뒤 [이어서], 예: 펜 바꾸기) |

## 배열 찍기

| 칸 | 기본 | 뜻 |
|---|---|---|
| 웰 판 | 24 · 96 · 12 · 6 웰 바로 넣기 | 줄 · 칸 수와 간격 |
| `rows` · `cols` | 4 · 6 | 1 – 26 줄 · 1 – 48 칸 |
| `px` · `py` | 19.3 · 19.3 mm | 칸 간격 |
| `wells` | 비움 = 전부 | `A1`, `B2-B5`, `C`(한 줄), `3`(한 칸 열) |
| `order` | 줄마다 왼쪽부터 | `snake` = 지그재그 |
| `dz` | 0 | 칸에서 내려가는 높이 (−3 – 100) |
| `g1` · `dwell` · `g2` | 없음 · 0.5 s · 없음 | 그리퍼 먼저 → 기다리기 → 그리퍼 나중 |

원점은 A1 이다.

## 파일

| 형식 | 확장자 | 읽는 것 |
|---|---|---|
| G-code | `.gcode` `.nc` `.ngc` `.gc` `.tap` | G0 G1 G2 G3 G4 G17 G20 G21 G90 G91 G94, M0(멈춤) · M3 S(펜 내림) · M5(펜 들기) |
| SVG | `.svg` | path · 도형 요소 · transform, mm 크기 그대로, 배율 칸 |
| 좌표 | `.csv` `.txt` | 줄마다 `x, y[, z]` (판 mm), 빈 줄 = 새 획, `#` 뒤 무시 |

## 작업 목록

- 항목마다 x · y · 돌림(·SVG 배율)을 바꾼다. ⊕ = 판 가운데로, ↑↓ = 순서, × = 지우기.
- x · y 기준: 도형은 가운데, 글씨는 시작, 배열은 A1, 파일 · 사진은 왼쪽 아래.
- [저장] · [불러오기] = `jobs/<이름>.json`. 만들던 작업은 브라우저에도 남는다.
- 판 밖으로 나가는 항목은 판 그림에 주황으로 보이고, 계획에서 거절된다(판 밖 허용 margin 0 – 50 mm).
