# 10. 한계 · 다음

## 한계

| 항목 | 지금 |
|---|---|
| 판 | 평면 하나. 곡면 · 기울어진 물체 위는 안 됨 |
| 공구 방향 | 작업 내내 시작 자세 그대로 (판 법선으로 돌리지 않음) |
| 공구 | 하나. 작업 중 바꾸기는 '멈춤' 항목으로 사람이 |
| 정확도 | 계획 단계 오차는 0.003 mm 이지만 실물 선 위치 오차는 미측정 |
| 누르는 힘 | 위치 제어라 판 높이 오차가 그대로 힘 변화가 됨 |
| 충돌 | 로봇 · 공구와 주변 물체 충돌 검사 없음 |
| 사진 → 선 | 흑백 문턱 하나. 회색조 · 색 구분 없음 |
| 글꼴 | 영문 대문자 · 숫자 · 기호 일부 |

## 다음

1. **실물 정확도 측정** — A4 에 10 mm 격자 · 원 20개를 그려 600 dpi 스캔, 선 위치 오차 분포를 잰다.
2. **스프링 펜 홀더** — 그리퍼가 평평한 블록을 쥐고, 펜은 블록 안에서 스프링으로 눌린다. 판 높이 오차를 스프링이 흡수한다.
3. **곡면 높이 지도** — 판 위 여러 점의 높이(공구 끝을 대거나 깊이 카메라)로 z 를 보간해 휜 판 · 한천 배지 · 완만한 곡면을 따라간다.
4. **3D 물체** — 깊이 카메라 점군 → 면 · 법선 추정 → 2D 무늬를 면에 투영, 공구를 법선으로 기울인다.
5. **선 굵기** — 굵은 선을 펜 굵기 간격으로 여러 번 나란히 긋는다.
6. **분주 공구** — 같은 경로를 스포이드 · 주사기로: 길이에 비례해 짜며 그리기, 점마다 정해진 양.
