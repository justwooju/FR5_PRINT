# 06. 실행 · 멈춤 · 이어서

## 실행 ⚠

- [시작] → 확인 창 → 실행. 진행(동작 번호 · 지난 시간 · 남은 시간 · 뒤처짐)이 머리띠와 판 그림 색으로 보인다.
- 속도 25 · 50 · 75 · 100 %. 도는 중에도 바꾼다(느리게만, 길은 같고 시간만 늘어남).
- [미리 돌려보기]: 판 그림 위에서 공구 끝이 가는 길을 빨리 돌려 본다(로봇 안 움직임).

## 멈춤

| 방법 | 동작 |
|---|---|
| [멈춤] · Space · Esc | 그 자리에 선다 (글 상자 안에서는 Esc) |
| [획 끝에서 멈춤] | 지금 동작을 끝내고 들어 올린 뒤 선다 |
| 작업 안 '멈춤' 항목 · G-code M0 | 그 자리에서 서고 [이어서]를 기다린다 |
| 제어판 조작 상태가 꺼짐 | 멈춤 |
| 뒤처짐 | 로봇이 명령보다 5° 넘게 0.6 s 뒤처지면 멈춤 |
| 끝 확인 | 끝 · 멈춤 자리에 3 s 안에 1° 안으로 오지 않으면 멈춤 |
| 제어판 [정지] · 비상정지 | 제어판 쪽에서 멈춤 |

## 이어서 ⚠

- 멈춘 동작(또는 다음 동작)부터 **지금 자리에서** 다시 계획한다. 판 가까이에서 멈췄으면 먼저 곧게 들어 올린다.
- 손으로 로봇을 옮겼거나 조그로 움직였다면 [계획 보기]부터 다시 한다.

## 바로 따라 그리기 ⚠

- 그리기 탭 [바로 따라 그리기] → 확인 창 [켜기].
- 판 그림에 획을 하나 그릴 때마다(손을 떼면) 그 획만 계획 · 검사해 곧바로 그린다. 로봇이 그리는 동안 그린 획은 모아 두었다가 다음에 함께 그린다.
- 획 사이에는 옮기는 높이로 들어 둔다(처음 자리로 돌아가지 않음).
- 검사에 걸리거나 멈추면 꺼지고, 못 그린 획은 그리기 탭에 남는다. Space = 멈춤 + 꺼짐.

## 실행 기록 `runs.jsonl`

한 줄 = 실행 한 번.

| 키 | 뜻 |
|---|---|
| `start` · `stop` | 시작 · 끝 시각 |
| `name` · `plan` | 작업 이름 · 계획 id |
| `start_op` · `n_ops` | 시작 동작 번호 · 동작 수 |
| `air_dz` · `tool_len` | 허공 높이 · 공구 길이 |
| `end` | `done` · `paused` · `stopped` · `error` |
| `why` | 멈춘 까닭 |
| `worst_lag` | 최대 뒤처짐(°) |
| `op` · `k` · `n` | 끝난 동작 · 명령 번호 |
